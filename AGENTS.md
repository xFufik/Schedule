# AGENTS.md

## О проекте

Schedule — Android-приложение для сравнения расписаний двух учебных групп из разных университетов.


## Источники расписаний

1. АлтГУ:
   https://www.asu.ru/timetable/students/8/2129442024/?date=20261116-20261122

2. АлтГТУ, группа С-61:
   https://www.altstu.ru/m/s/0300022502/

Расписания должны загружаться с сайтов, а не храниться в коде приложения.


## Основные функции

1. Загрузка расписаний обеих групп.
2. Преобразование расписаний к единой модели данных.
3. Поиск временных пересечений занятий по календарным датам.
4. Отображение пересечений в удобном интерфейсе.
5. Ручное обновление расписаний.
6. Выбор недели для сравнения.

При сравнении учитывать частичные пересечения занятий и исключать дублирующиеся интервалы.

## Правила разработки

- Использовать Kotlin для программной логики и XML для интерфейса.
- Разделять загрузку данных, обработку расписаний и интерфейс.
- Не выполнять сетевые запросы в главном потоке.
- Не добавлять ненужные библиотеки и сложную архитектуру.
- Обрабатывать ошибки сети и отсутствие расписания.
- Не изменять существующую функциональность без необходимости.
- По возможности проверять компиляцию проекта после изменений.
